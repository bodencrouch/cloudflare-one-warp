# KDE / NetworkManager

Integrate WARP-style connectivity with **NetworkManager** on Linux — MASQUE, WireGuard-style, and local proxy profiles.

::: warning
Cloudflare WARP uses `warp-svc` and interface `CloudflareWARP`. NM profiles are **companion** connection stubs for Plasma integration, not a replacement for warp-cli.
:::

## Profiles

| Profile | Purpose |
|---------|---------|
| `cloudflare-one-warp-masque` | MASQUE mode companion |
| `cloudflare-one-warp-wireguard` | WireGuard mode companion |
| `cloudflare-one-warp-local-proxy` | System proxy alignment |

Generated by `lib/networkmanager/profiles.mjs`, synced via daemon.

## CLI

```bash
cloudflare-one-warp-nm list
cloudflare-one-warp-nm import masque
cloudflare-one-warp-nm import wireguard
cloudflare-one-warp-nm import local-proxy
cloudflare-one-warp-connect masque
```

## KDE import

If `nmcli connection load` returns **access denied**, use **Settings → Network → Import VPN connection** and pick the generated keyfile under the install tree.

## Dispatcher

`packaging/networkmanager/99-cloudflare-one-warp` hooks connection up/down events.

## Proxy sync

```bash
cloudflare-one-warp-kde-proxy-sync
```

Aligns KDE/system proxy with daemon local-proxy settings.

Full detail: [NETWORKING.md](https://github.com/bodencrouch/cloudflare-one-warp/blob/main/docs/NETWORKING.md).
